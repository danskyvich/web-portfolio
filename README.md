# 📁 web-portfolio
My very first portfolio highlighting my CS and personal projects. Built using the React + Vite frontend framework.
# ⚙️ Tech stack
My portfolio is built using React + Vite, with vanilla CSS for styling purposes and vanilla JS for the logical backend. This website also utilises Framer Motion as the primary animation library (paired with vanilla CSS built-in animations). 

# 💻 Deployment
I'm planning to deploy this website to Vercel after I verify and validate my portfolio in the local production build.
